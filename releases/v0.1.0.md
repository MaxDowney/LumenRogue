# LumenRogue v0.1.0 — first public Windows build

A terminal roguelike with turn-based exploration and continuously animated,
true-colour lighting. Town shops, branching conversations, procedural dungeon
biomes, equipment, class skill trees, spells and explosive effects are included.

## Download and play

Download **LumenRogue-CPP.exe** for a standalone Windows x64 executable, or
**LumenRogue-v0.1.0-windows-x64.zip** for the executable and quick-start guide.
The GitHub “Source code” archives are for building the game, not playing it.

Requires 64-bit Windows 10 or 11 and a terminal with ANSI true-colour support.
Windows Terminal is recommended. No .NET runtime, additional DLLs, installation
or external asset files are required. Use a writable folder for saves.

This early release is unsigned. A SHA-256 checksum file accompanies the downloads
so the downloaded bytes can be checked; it is not a code-signing certificate.

## Highlights

- Animated torchlight, soft shadows, coloured spell lighting and explosions.
- Character creation with four ancestries and four classes; equipment and skills.
- Towns, dialogue trees, connected quests and six main dungeon depths.
- Shop Buy/Sell tabs, item artwork, gear comparisons, quantities and stack sales.
- Fullscreen startup/resize fixes and responsive terminal layouts.
- Optional sound effects and reduced-motion controls.

## Controls

Arrow keys or WASD move; Y/U/B/N move diagonally. E interacts, I opens the pack,
Z opens spells, T opens skills, X inspects, Tab opens quests, and ? opens help.
F5 saves, F9 loads, F7 toggles sound, F8 toggles reduced motion, and Q opens quit.
In shops, B/S or Tab switches Buy/Sell; +/- changes quantity; Enter trades.

## Validation and limitations

The native regression suite covers world generation, progression, combat,
lighting, shops and save/load. Layout and native Windows pseudoconsole resize
checks are included in the repository. Saves are local and are not bundled.
This release is for Windows x64 only; gameplay balance and presentation are
still being developed. The C# implementation is retained as an earlier version.
